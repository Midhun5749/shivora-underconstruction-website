# 🚧 SHIVORA – Under Construction Website

A premium "Coming Soon" landing page created for **SHIVORA EXIM**, designed to establish a professional online presence while the official website is under development. The page features a clean, modern design with responsive layouts, smooth animations, and clear business branding.

## 🌐 Live Demo

https://shivora-underconstruction-website.vercel.app/


## ✨ Features

- Premium under-construction landing page
- Modern and minimal UI
- Fully responsive design
- Company branding and logo integration
- Smooth animations and transitions
- Business contact information
- Mobile-friendly layout
- Fast loading performance
- SEO-ready structure
- Clean and maintainable code
